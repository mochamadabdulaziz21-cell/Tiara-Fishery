# Tiara Fishery Management

PWA siap di-host di GitHub Pages.

## GitHub Pages
1. Buat repository baru.
2. Upload seluruh isi folder ini ke root repository.
3. Settings → Pages → Deploy from a branch → main / root → Save.
4. Buka URL GitHub Pages melalui Chrome di HP, lalu pilih **Install app / Tambahkan ke layar utama**.

Nama aplikasi terpasang: **Tiara Fishery Management**.
